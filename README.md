# CodeCrush 💔➡️💪

A public learning notebook documenting my journey to becoming a better Software Engineer through Data Structures & Algorithms.

## 👨‍💻 About Me
I’m a **Java Backend Engineer Aspirant** and a **2026 CSE graduate**, currently preparing for Software Engineering interviews.

I’m also documenting this journey on YouTube. This repository is the long-term companion to that journey.

## 🎯 Purpose
CodeCrush is designed to be more than a solution bank.

It is a personal but public learning system that helps me:
- solve problems consistently,
- revise interview patterns quickly,
- connect code with explanation videos,
- and track growth over years.

## 🧭 Learning Identity
This repository follows one principle:

> I’m not here to teach from a pedestal. I’m here to document, explain, and grow in public.

## 🚀 Workflow
Every problem follows the same workflow:

```text
Notion
    ↓
Understand the Problem
    ↓
Solve in Java
    ↓
Document the Approach
    ↓
Commit to GitHub
    ↓
Record YouTube Video
    ↓
Revise Before Interviews
```
