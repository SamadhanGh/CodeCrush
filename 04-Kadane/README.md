# Kadane

## 📖 Introduction
This folder covers maximum/minimum subarray style optimization using running totals and local/global best tracking.

---

## 🧠 When should I think about this pattern?
- Need best contiguous sum/product.
- Negative values reset usefulness.
- O(n^2) brute force feels too heavy.
