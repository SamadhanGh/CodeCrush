# Fast Slow Pointer

## 📖 Introduction
This folder covers tortoise-hare style traversal where two pointers move at different speeds, usually on linked lists or cycle-detection style arrays.

---

## 🧠 When should I think about this pattern?
- Need cycle detection.
- Need middle element in one pass.
- Need to detect periodic behavior.
