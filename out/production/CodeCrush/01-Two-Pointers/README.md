# Two Pointers

## 📖 Introduction
This folder covers problems where two indices move through data (often arrays/strings) to reduce nested-loop work into linear scans.

---

## 🧠 When should I think about this pattern?
- Sorted input is given.
- Need pair/triplet conditions.
- Need to shrink or expand from ends.
- Need in-place rearrangement with index movement.
