# Prefix Sum

## 📖 Introduction
This folder covers cumulative-sum techniques used to answer range queries and optimize repeated sum computations.

## 🧠 When should I think about this pattern?

- Subarray sum target checks.
- Need O(1) range retrieval after preprocessing.
