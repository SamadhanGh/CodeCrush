# Cyclic Sort

## 📖 Introduction
This folder covers index-placement techniques where values map naturally to positions.

---

## 🧠 When should I think about this pattern?
- Values in range [1..n] or [0..n].
- Need missing/duplicate/corrupt numbers.
- In-place linear-time requirement.
