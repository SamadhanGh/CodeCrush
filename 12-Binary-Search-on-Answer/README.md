# Binary Search on Answer

## 📖 Introduction
This folder covers optimization problems solved by binary searching feasible answers over a monotonic condition.

---

## 🧠 When should I think about this pattern?
- Need minimum/maximum feasible value.
- Direct construction is hard.
- Feasibility function is monotonic.
